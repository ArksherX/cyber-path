    How this works

    One way in, seven domains

    Everyone starts at Foundations (Level 1). Then pick one main domain (Level 2) and go deeper with its advanced paths (Level 3). Add a side domain if you want to learn two things at once. If you already know the basics, skip ahead. Not sure which domain? Take the role quiz below.

    1. Type everything by handNo copy and paste until you can explain the line.
    2. Predict, then runSay what you expect before you run a command. Surprises are where you learn.
    3. Write it downKeep notes and a log. A finding you cannot explain later is a finding you did not learn.
    4. Labs onlyPractise on your own machines and on platforms built for it. Nothing else.
    5. Explain it backEach week, explain what you learned in two minutes. If you cannot, repeat the week.
    6. Pace yourself8 to 12 hours a week is plenty. Splitting a week in two is fine. Quitting is the only mistake.
    Safety and legal. Everything here is for legal, authorised learning only. Test systems you own or have written permission to test. Unauthorised access is a crime under Nigeria's Cybercrimes (Prohibition, Prevention, etc.) Act 2015 and similar laws elsewhere. This path contains no destructive techniques: no data destruction, no denial of service, no ransomware.

    Choose your lane

    Which domain fits you?

    Everyone does Foundations first. Offensive is one domain among seven, not a prerequisite for the others. Pick the domain that fits you, then use My route to build your plan. Offensive has six advanced electives (pick one or two). Every other domain has one advanced path. You can pivot later, because the core skills carry over.

    DomainYou may like it ifDo firstTypical roles
    OffensiveYou enjoy breaking things and solving puzzlesFoundationsPenetration tester, red teamer, bug bounty hunter
    Defensive / SOCYou like watching systems, spotting patterns and acting fastFoundationsSOC analyst, incident responder, detection engineer
    Threat Intel and DFIRYou like research, writing and investigationFoundationsThreat intelligence analyst, forensic investigator
    DevSecOpsYou like code, automation and pipelinesFoundations plus basic codingDevSecOps engineer, application security engineer
    AI SecurityYou are curious about models and how they failFoundations plus Python basicsAI red teamer, AI security engineer

    Security Engineering and CloudYou like designing and building systemsFoundations plus some Linux and networkingSecurity engineer, cloud security engineer, infrastructure engineer

    Pivot tip. Finish Foundations before choosing. Then try the first two weeks of two domains. Keep the one you finish the weekly task for without being pushed.
